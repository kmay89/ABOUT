BEFORE AND AFTER THE GRIDS

What else a Bambu Lab P2S wants for amazing prints

Swatch finds the settings that decide how a surface looks. The ones below decide whether any of it holds — do them in this order, and the grids get easy to read.

  1. Dry the filament. Most “bad ironing” and “pitted top” is moisture. PLA 4 h at 55 °C, PETG 6 h at 65 °C, in the AMS with desiccant after. A top surface that pops and leaves pinholes will never iron flat.
  2. Let the printer calibrate flow dynamics. The P2S measures pressure advance itself with its eddy-current sensor; leave Flow Dynamics Calibration ticked on the print dialog, or run it from the Calibration tab per filament. Every grid here assumes it has been done.
  3. Flow rate, coarse then fine. Bambu Studio › Calibration › Flow rate. Both passes. The result goes into the filament profile’s flow ratio; the first-layer and top-surface ratios in Swatch multiply it, so set it first.
  4. Max flow rate. Calibration › Max flowrate, once per filament. Where the line breaks up is the ceiling; set the filament’s max volumetric speed a touch below it, and no wall-speed test will fool you with under-extrusion.
  5. Temperature. Calibration › Temperature tower. Cooler for sharper detail and less stringing, hotter for stronger layers and a glossier wall — it changes gloss as much as any setting here.
  6. Then the Swatch grids, in this order: first layer → top surface flow → ironing → walls → seam. Each one leans on the one before.
  7. Choose the plate on purpose. Textured PEI gives a matte, grained bottom that hides everything; smooth PEI or the Cool Plate gives a gloss bottom that shows everything, which is where the first-layer grid earns its keep.
  8. Top shells. Five top shell layers over 15 % gyroid or cubic, or set Top shell thickness to 1 mm. Fewer and the infill ghosts through the surface; no setting in this lab can hide it.
  9. Walls. Three loops, Precise wall on, order inner / outer / inner if your version has it. Try Slow down for curled perimeters and keep the outer wall at the speed the walls grid chose.
  10. Judge in good light, at a low angle to a window or a lamp, and in photos: a phone camera at a glancing angle shows ridges your eyes forgive.

The guide

What a grid is

A test is two settings and a list of values for each. Every pair becomes a coupon — a small tile, pillar or cylinder — that prints with that pair, and with its values printed on it so the plate can be read without the legend. The file is a 3MF; inside it, next to the shapes, is the same per-object settings list Bambu Studio writes when you right-click a part and add a setting. Open it as a project and each coupon arrives with its settings already on it.

Opening it

Use File › Open Project, or drop the file on the window and pick open as project. Bambu Studio will note that it loaded “geometry data only”: that is right, because the file carries no printer, filament or process profile — yours stay selected, and the coupons only differ from them where the test says. Do not use File › Import, which strips settings from objects. To check, click a coupon: its settings appear under it in the object list on the right.

Printing it

Print the whole plate at once, with the filament you will use for real prints and the plate you will use. Keep the process profile you normally print with; the test adds its own differences. Expect the time the slicer says, not the rough figure on this page.

Reading it

The label on each coupon is its values in the order across / front-to-back, written short: .42 is 0.42, MLINE is the monotonic-line pattern, SC10 a 10 mm scarf. The first-layer tiles are read from underneath, where the label reads the right way round. The sheet lists every coupon in full.

Keeping the winner

Enter the winning values in your process profile and save it under a new name — one per filament, since flow is a property of the plastic. Ironing settings are under Quality › Ironing; the two flow ratios under Quality › Advanced (they appear in Developer mode: Preferences › Develop mode); the seam settings under Quality › Seam.

Other slicers

OrcaSlicer reads the same file the same way. PrusaSlicer and Cura open the coupons but ignore the Bambu settings list; use the sheet and set each coupon’s settings by hand as per-object overrides.
