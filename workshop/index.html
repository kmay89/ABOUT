The Workshop

Tools for the 3D printer, in the browser. No accounts, no uploads, nothing tracked, and they work with the aeroplane mode on.

Each one takes something you already have — a photo, a model — and hands back a file your slicer opens at 100 % scale, checked against your printer's plate (the Bambu Lab P2S by default, with the others in a menu). Nothing you drop in leaves your device: there is no server behind these pages to send it to. All of them are open source, MIT, in kmay89/ABOUT.

Tools

Hollow — Mold Studio Drop in an STL and get back the hollow of it: a two-part mold with alignment pegs, a pour spout and air vents; an open mold for flat-backed pieces, with a core for vessels; or a silicone master. It shows what will release and what is trapped before you print, and says how much concrete, resin or silicone to mix. ConcreteResinPlaster · wax · soapNew Luma — Lithophane Studio Turn a photo into a 3D printable picture made of nothing but thickness: a flat panel for a lighted frame, a curved nightlight shade, or a lamp that goes all the way round a tea light. A live preview lit from behind, a thickness test strip for your own filament and light, and printable frames and bases. PhotosLamps & frames Cubby — Drawer Organizers Type the inside of any drawer, drag bins across a grid that fills it to the millimetre, and download one file with every part placed on the plate. The bins fit each other and the drawer: no screws, no glue. Kitchen · desk · garage3MF per plate Swatch — Surface Test Lab Four sessions of small labelled coupons, each carrying its own settings — dimensions and fit for the calipers, then first layer, top-surface flow and ironing, walls and seams — in one 3MF that opens in Bambu Studio as a project with no warning. Print a plate, measure or hold it to the light, keep the winner. With a checklist of what else a P2S wants first. Dimensions & fitIroningWalls & seamsNew Cameo — Photo Figurine Studio Drop in a photo of a pet, a person, anything with an outline. It is cut out, its edges rounded over, and real depth laid into it by a model that runs on your own machine; out comes a relief figurine that prints flat with no supports, and a pedestal with a slot it stands in. One 3MF, ready for Bambu Studio. Pets & peopleAI on your machineNo supports Knurl — Surface Texture Studio Drop in any STL and lay a texture into its walls: knurling, hexagons, flutes, ripples, scales, leather, wood grain, brick. The relief is cut into the surface, fades out at the edges and stays clear of the plate, so it prints with no supports and hides layer lines instead of showing them. Then paint the first layer in a second colour, a pattern, your text or a logo, as a second part in the same 3MF: two layers of filament, one swap, a face that looks finished the moment it comes off the plate. On the bench

These tools are hand-written static pages: ES modules, a vendored copy of Three.js for the 3D view, and a web worker for the heavy geometry so the page stays alive while it thinks. There is no build step — clone the repo, serve the folder, and they run. Each has a README that explains the maths and a test suite that proves the files it writes are closed solids: npm run check:luma, npm run check:hollow, npm run check:cubby, npm run check:swatch, npm run check:cameo, npm run check:knurl.

They print on a Bambu Lab P2S here, but the files are ordinary STL and 3MF at 100 % scale, and the printer menu knows the plates of the common machines. If a tool gets something wrong for your printer, the source is the place to say so.
